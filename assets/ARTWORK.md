# Original artwork
Generated with the integrated ImageGen tool for this project on 26 September 2026.
The original generated PNG files remain in the Codex generated_images directory. Runtime assets are WebP copies at quality 88, preserving the full composition.

## Shared art direction
Use the original laboratory illustration as the visual reference: the same teal circular time portal, navy and amber painterly graphic-novel laboratory. Create a genuinely different physical camera viewpoint, not a crop or a colour filter. PIP is a small mechanical robot with exactly two correctly connected articulated arms and grippers and two legs. No extra hands, no limbs merging into furniture, no text, labels or UI.
